# Nikol Nakonechna — Portfolio

Personal portfolio of a UI/UX designer and frontend developer.

**Live:** https://nntrwx.github.io/portfolio/

## Featured case studies

- **GamePulse** — SaaS landing page & gaming stats dashboard (Figma, Next.js, Tailwind, GSAP)
- **KYO** — landing page for a Japanese cyber-minimalist fashion brand (UI/UX design in Figma)
- **Mochi** — skincare landing page with a routine-building quiz (Figma, React, Vite)

## Stack

React, Vite, React Router. Deployed on GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```
